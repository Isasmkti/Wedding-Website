# 💍 Wedding Website

A modern, elegant, and responsive wedding invitation website built with **Vue 3 (Vite)** for the frontend  
This project includes RSVP functionality, event timeline, and testimonials with a gold & white theme ✨.

---

## ✨ Features

- 🎨 Elegant **Gold & White** wedding theme
- 📅 Wedding timeline with smooth **AOS animations**
- 💌 RSVP form with guest messages
- 💬 Guest testimonials (company / partner wishes)
- 📱 Fully responsive design for desktop & mobile
- ⚡ Powered by Vue 3 + Tailwind CSS (frontend) and Express.js + Prisma (backend)

---

## 🛠️ Tech Stack

### Frontend
- [Vue 3](https://vuejs.org/) + [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [AOS](https://michalsnik.github.io/aos/) (scroll animation)
- [Font Awesome](https://fontawesome.com/) (icons)
