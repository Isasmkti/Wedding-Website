# Wedding Invitation Website

Website undangan pernikahan modern berbasis Vue yang dibuat dengan tampilan elegan, clean, dan responsive.
Project ini masih fokus di sisi frontend dan akan dikembangkan lebih lanjut untuk fitur RSVP dan guest interaction.

---

# Tech Stack

## Frontend

* Vue 3
* Vite
* Tailwind CSS
* Vue Router
* AOS Animation
* Font Awesome

---

# Fitur Utama

## Landing Section

Bagian pembuka website.

Isi:

* nama pasangan
* cover image
* tanggal acara
* opening text

---

## Couple Section

Menampilkan informasi pasangan.

Biasanya berisi:

* foto mempelai
* nama lengkap
* nama orang tua
* social media (optional)

---

## Event Information

Informasi acara pernikahan.

Contoh:

* akad
* resepsi
* lokasi
* maps
* jam acara

---

## Wedding Timeline

Timeline perjalanan hubungan atau rundown acara.

Menggunakan:

* scroll animation
* transition effect
* timeline layout

---

## Gallery Section

Galeri foto pasangan.

Fitur:

* responsive grid
* smooth hover effect
* lightbox preview (planned)

---

## RSVP Section

Masih tahap pengembangan.

Rencana fitur:

* konfirmasi kehadiran
* jumlah tamu
* ucapan tamu
* attendance status

---

## Wishes / Guest Message

Fitur ucapan tamu.

Planned:

* kirim ucapan
* tampil realtime
* pagination message

# Installation

## Clone Repository

```bash id="qjlwmq"

```

---

## Install Dependencies

```bash id="rtu84f"

```

---

## Run Development Server

